> - 小红书：《小红书社区规范》、《小红书社区公约 2.0》（2026-10 版）、《交易导流违规管理细则》（2025-03-12 生效）、《直播带货管理规则》、《商业化风险积分管理规则》（2025-07-21 生效）
> - B站：《bilibili主播直播规范 V2.8》（2026-03-09）、《bilibili社区公约》
> - 小红书《社区直播规范》官方全文未能获取，小红书直播部分以上述文档推定，判断时保守从严。

## 一、四平台严格度速查（取最严）

| 维度 | 最严平台 | 最严标准 |
|---|---|---|
| 处罚烈度 | 视频号 | 严重违规直接永久封禁；可连带绑定微信号功能，身份证、手机号禁止再注册视频号 |
| 投资理财 / 荐股 | 视频号 | 投资、融资类直播（荐股、网贷、推销金融产品、证券期货有偿咨询）= 严重违规，永久封禁；抖音未认证仅三级 |
| 宗教 / 新闻时政 | 视频号 | 宗教类直播、新闻时政类直播 = 严重违规，永久封禁 |
| 教人做副业变现 | 视频号 | 以"教你运营账号做副业变现"为噱头并引流到直播以外渠道 = 违规（自媒体运营、电商运营、直播运营、带货运营及变现都算） |
| 导流 | 小红书 | 位置覆盖笔记、评论、主页资料、置顶消息、直播；形式含截图、水印、小程序、口令、多账号配合、暗示索取；最高永久封号 |
| 着装 | B站 / 视频号 | B站有量化尺寸；视频号点名瑜伽裤、开叉至臀、光脚、鼻唇钉、纹身 |
| 真实性 / 人设 | 小红书 | 不得虚构收入、财富、学历、情感经历；摆拍虚假生活场景也算 |
| AI 内容 | 小红书 / 视频号 / B站 | AI 生成、合成或剧情演绎内容必须显著标注；B站另禁 AI 冒充他人 |
| 专业资质 | B站 / 视频号 | 财经、医疗、法律、教育必须先认证；视频号金融、健康、法律科普直播需单独准入 |
| 广告 / 商业推广 | B站 / 小红书 | 未经平台许可不得发广告、悬挂二维码；商业推广须声明并走官方渠道（B站花火 / 小红书蒲公英） |

## 二、视频号

### 1. 处罚体系
- **严重违规 → 永久封禁账号**；其他违规分重、中、轻度：弹窗提醒、减少推荐、中断直播、禁播、封禁账号。
- 主播安全信用分初始 100 分，按违规场次、类型、级别扣分，越低处置越重（轻度限流 → 中度限流 → 重度限流 → 禁播）。当场整改且本场不再违规，扣分减半。
- 运营规范：违规可暂停或永久停止视频号**及对应微信号**的部分功能；身份证件、手机号可能被禁止再注册视频号。
- 申诉：直播处置可发邮件到 weixinlive@tencent.com（1–2 个工作日复核）；视频号内容在 创作者中心 → 帮助与反馈 申诉。

### 2. 严重违规（永久封禁），抖音没有列到这个级别的
- 宗教类直播内容。
- 新闻时政类直播内容。
- 投资、融资类直播（荐股、网贷、推销金融产品、证券或期货有偿咨询）。
- VPN 翻墙软件营销或传授翻墙技巧；违规炒作虚拟货币或教人非法获取虚拟货币。
- 宣传推广需特殊资质的商品服务：彩票、医疗、药品、医疗器械、农药、兽药、保健食品、特医食品。
- 募捐、筹款类直播。
- 宣传网络禁播黑名单主播或帮其引流。
- 烟草类产品直播。

### 3. 视频号独有 / 更严的点
- **副业变现引流**：以教人运营平台账号做副业变现为噱头，并把用户引流到直播以外渠道 = 违规。
- **标题封面**：不得写地理距离、位置或引流用语，如"附近100米""加微"。
- **口令码**：不得传播第三方生成的识别码、口令、特殊字符；不得传播被微信限制的链接或域名。
- **利诱互动**：不得用奖励诱导分享、关注、点赞、评论（"关注抽奖""集赞""转发领资料""分享多一次抽奖"）；不得用诅咒、胁迫语言要求点赞。
- **噱头诱导**：不得用"免费领福利""现金红包返利""赚取高额佣金""网赚/兼职招聘"做噱头，诱导关注、送礼、加热。
- **虚假人设**：不得使用虚假或未经平台核实的身份、头衔、称号、荣誉。
- **财经引流**：不得以分享股市分析、行业分析、投资技巧为由把用户诱导、引流去推广营销。
- **账号资料**：名称、头像、简介不得夸大、误导、过度广告；名称不得用中国或外国国家名、单独地名、日常通用词（正能量、养生、星座、运势等），不得用手机号做名称。
- **内容**：夸张标题与内容严重不符、"快速赚钱经历或成功经验"类炫富、卖惨推广商品、风水运势、批量同质化内容都违规。
- **医疗科普**：有大量专门规定，包括"根治""包治百病""祖传秘方""一招见效"、偏方食疗治病、无辨证穴位治病、正骨拔罐针灸放血教学、评论区问诊、引流到个人联系方式等。
- **直播场景与行为**：必须用普通话；不得在床上、卫生间、酒店暧昧场景直播；不得在酒吧、网吧、夜店、沐足店直播；不得抽烟；不得展示饮酒、酗酒；不得大面积裸露纹身；不得展示鼻钉、唇钉；不得边驾驶边直播；禁止无人直播、录播、矩阵号直播、长时间挂机或拍天花板。
- **着装（量化）**：背部裸露低于肩胛骨，或背部裸露面积超过 1/2；上衣露出下胸线；非运动场景穿瑜伽裤；裤腰低于胯骨；下装两侧开叉至臀部附近；未穿鞋完整露足营造低俗氛围；男性赤裸上身。
- **其他营销**：未经许可不得推广电话卡、流量卡、物联网卡、宽带资费；不得以法拍房名义推广、交易、引流。
- **特殊准入**：金融科普、健康科普、法律科普、婚恋介绍、体育赛事直播需先按对应准入标准申请。
- **AI 与演绎**：AI 生成或合成内容、剧情演绎的虚构内容必须显著标识。

## 三、小红书

### 1. 处罚体系
- 内容：扣除作弊数据、限制展示范围、禁止展示。账号：限制功能、限流、禁言、封禁。
- 交易导流：警告、限制直播间流量、中断直播、限制直播功能、关闭直播权限（一天到永久）、关闭商品分享、封号；**商家每次扣 10–25 分，账号信誉分每次扣 0–12 分**。
- 商业化风险积分（投广告账号，年度累计）：≥3 分下线违规笔记、预警并不允许投广告；≥6 分冻结 14 天；≥9 分冻结 30 天；≥12 分冻结 45 天；**≥15 分永久冻结**。P0（涉政、涉黄、涉赌、涉毒，以及减肥、壮阳、丰胸、增高、私处美容等"黑五类"）直接扣 15 分。
- 申诉：APP → 帮助与客服 → 笔记/账号申诉。

### 2. 交易导流（最全面）
只允许通过小红书商城、直播间购物车、官方留资组件交易。以下都算违规：
1. 传播个人或社群联系方式，或其他平台的账号、店铺信息。
2. 引导用户查看、添加、提供、交换私域或三方信息（包括暗示对方来要）。
3. 发布其他平台的链接、口令、截图、水印、二维码、小程序，或把这些信息直接、变形或植入到图文里。
4. 多个账号配合，通过评论、收藏、账号跳转引导脱离平台交易。
5. 其他明示或暗示把用户引到私域、站外的行为。

覆盖位置：直播内容、置顶消息、笔记、评论、用户资料。直播带货中，用手势、代称、黑话引导私下交易也算。

### 3. 真实性与社区公约 2.0
- 不得塑造虚假人设：**夸大财富、伪造学历、虚构收入数字**、编造情感经历、摆拍虚假生活场景。
- 使用 AI 辅助创作的内容应主动标注"AI生成"。
- 避免炫耀远超常人的消费能力（是否对别人有用是判断炫富的标准）。
- 避免夸张、猎奇的标题和封面，内容要文题相符。
- 未取得职业资质不得给他人提供**医疗、投资、购房建议**。
- 分享的产品必须有真实体验；过分照搬商家指引或官方宣传语算违规。
- 不得编造竞争对手谣言、恶意批量举报、盗用他人肖像做商业宣传、攀附其他品牌营销。

### 4. 其他
- 禁止售卖高风险类内容（医美整形、医疗器械）；代购、转卖、拼单类营销内容不鼓励。
- 违禁物品清单里明确包括投资理财产品和翻墙软件。
- 2026-09 发布《社区金融生态公约》，"变相导流站外"列为禁止行为之一。
- 直播打赏：营造暧昧气氛、编造卖惨剧情、低俗诱导打赏属于重点整治对象。

## 四、B站

### 1. 处罚体系（《主播直播规范 V2.8》）
- **A 类（严重）**：扣 12 分 SAN 值；封禁直播账号或开播权限 1 年到永久；列入直播黑名单；永久封禁 B站账号；限制违规设备开播。
- **B 类（一般）**：警告、切断直播流、封禁直播间 1–90 日、每次扣 SAN 值 3–6 分、永久取消推荐或 PK 连麦资格、清除违规所得人气，情节严重升级为 A 类。
- **C 类（轻微）**：警告、断流、封禁 2 小时–7 日、每次扣 SAN 值 3 分、打回封面标题。
- 累犯（12 个月内同类违规 2 次以上）或情节严重会升级处罚。
- 社区公约：视频、图文内容会被删除、限流、加提醒标识；账号可能被限制营利权限；粉丝 50 万以上需前台实名。

### 2. A 类（严重），比抖音更严的
- 算命卜卦、探灵、招魂、请仙、法事现场等封建迷信直接算 A 类。
- 非公务人员穿政府、党派、警察、军队、法院、城管等制服或佩戴相关标识做娱乐直播。
- 调侃外交、军事、政治、历史、时事（自然灾害、重大事故）并造成恶劣影响。
- 通过直播或引导到其他社交媒体传播色情，包括诱导加入低俗粉丝群、福利群。

### 3. B 类（一般），要注意的
- 时政、社会新闻类内容及相关评论谈话。
- 宣扬不当消费观和价值观，如炫富、拜金、**不劳而获**、鼓吹靠颜值吃饭。
- 医疗、财经、法律、教育等专业内容**必须先取得执业资质认证**。
- **未经平台同意发广告**：悬挂二维码、图文、视频、网址、语音，把用户引流到第三方应用都算。商业广告必须走 B站官方商业渠道下单。
- 网络兼职广告、VPN 广告、返利广告、未经授权的第三方代理销售广告、在直播间贴"广告位招租 + VX"。
- 直播其他平台内容，或宣传、引导观众去其他直播平台。
- 直播间任何形式的导流；用二维码、网址、图文、语音诱导私下交易。
- 校外培训：学龄前和中小学（含高中）学科类培训内容及其广告。
- AI：未经授权用 AI 生成他人形象、冒充他人或公职人员；AI 主播或 AI 生成内容没有显著标识。
- 礼物：爆奖返现、变相返现、承诺表演后不兑现；虚假抽奖、内定抽奖、不兑奖。
- 网约车、户外生存、体育赛事、演唱会直播需事先获得平台同意。
- 平台签约主播不得在其他平台直播。

### 4. C 类（轻微）
- 持续爆粗口；抽烟喝酒（醉态直播算情节严重）。
- **展示支付宝、微信二维码等平台外交易信息**。
- 刻意展示平台外的评论、弹幕。
- 用虚假人设、夸大封面标题博流量，或封面标题蹭热点但内容无关。

### 5. 着装（量化，取最严时以此为准）
- 女性：刻意露乳沟或内衣；背部裸露超过上半部 2/3；下装腰部低于骨盆；短裙短裤下摆高于臀下线；胸部裸露超过 1/3；腹部裸露超过下胸线到胯骨距离的 1/2；3D 紧身衣凸显胸臀。
- 男性：赤裸上身、露内裤、贴身紧身裤、裤腰低于胯骨。
- 场景：紫、红、粉等暧昧昏暗灯光；凌乱床铺；在 KTV、酒吧、夜总会、洗浴、足疗、按摩店直播。
- 镜头：从上往下拍胸、从下往上拍腿臀；展示纹身。

### 6. 社区公约（视频与图文）
- 违规推广：钓鱼诈骗推广；山寨盗版；可能损害用户利益的链接、二维码（含关注导流、营销引流、交易转化用途的网盘链接和二维码）。
- 未经资质认证的财经、医疗、司法、教育推广；含第三方商业推广但未做商业声明；未使用 B站官方经营推广工具。
- 诱导用户去第三方平台注册、关注、交易、消费的内容（含第三方链接、二维码、账号、标识）会被删除或限流。
- 宗教：过度展示教义、教规、仪式；以宗教名义做商业宣传；没有宗教资质发布宗教内容。
- 规范用语：如"中国大陆"英文用 Chinese mainland；"新疆维吾尔自治区"；地图必须完整。
