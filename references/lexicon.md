# 高危词库 + 替代说法

等级：🔴 一级/封号　🟠 二级/重罚　🟡 三级/断播　⚪ 限流。适用场景标注：短=短视频，播=直播，车=挂车，投=投流。未标注即全场景。
谐音、拼音、缩写、符号替代（xx 拼音、"V""薇""绿泡泡"）一律视同原词。

## 1. 政治 / 社会 / 宗教（🔴）

| 词 / 类 | 替代 / 处理 |
|---|---|
| 中国、美国、各国领导人姓名（含昵称、谐音）、政策、政府 | 不说；必须提及地域时用"我们这边""国内市场" |
| 西藏、新疆、香港、澳门、台湾 | 不碰；如必须提，香港/澳门写"中国香港""中国澳门" |
| 风口事件、社会热点、灾难事故（飞机失事、火灾、爆炸、疫情） | 不评述、不调侃 |
| 公安、检察院、法院、卫生（局）等机关名称 | 不说 |
| 中国太内卷、马上爆发经济危机、中外生活就业对比、唱衰 | 不说（视频号身份证封号） |
| 佛教、道教、伊斯兰教、耶稣、默罕默德、传教 | 不说；背景不放佛教音乐、不在寺庙前直播 |
| 算命、命理、风水、玄学、法术改命 | 不说；此类直播间控制在线人数 |
| 国旗、国歌、国徽、人民币、军旗、军歌、军徽（恶搞/不当使用）、军警制服、红领巾 | 不使用 |
| 国家重大活动/纪念日、机关名义做商业宣传、国宴/特供/机关专供 | 不说 |

## 3. 诈骗嫌疑 / 收益承诺（🔴视频号 · 🟠抖音）

| 高危表达 | 合规改写方向 |
|---|---|
| 月入 10 万 / 月入 5 万 / 跟我学月入 X | 删除收益数字，改讲"方法""经验""做法" |
| 财富自由、白手起家、躺平不干、躺赚、被动收入 | 删除；改讲"把一件事做扎实" |
| 普通人副业变现、宝妈宝爸、宝爷爷宝奶奶 | 改"想学 XX 技能的朋友""创业者" |
| 零基础小白包学包会、学不会包退、学完就能赚 | 改"零基础也能跟上课程节奏"（不承诺结果） |
| 展示学员收入截图/案例做诱导 | 不展示收入；可讲学员做了什么、不讲赚了多少 |
| AI + 赚钱 / AI 副业 | 改"AI 提效""AI 工具使用" |
| 新风口、赚钱秘籍、高收益 | 删除 |

## 4. 变现类词（⚪限流 · 播/车/投更严，618 前后视频号重点抓）

## 8. 广告法极限词（车/投必查，口播/背景板/字幕/标题/商详页全禁）

- **"最"类**：最佳、最具、最赚、最优、最优秀、最好、最大、最大程度、最高、最高级、最奢侈、最低、最低级、最低价、最便宜、最流行、最受欢迎、最时尚、最先进、最新、最新科技、最新科学、最新技术、最先进加工工艺

- **时间/程度**：史无前例、前无古人、永久、无敌
- **"级/极"类**：全球级、宇宙级、世界级、国家级、极品、极致、顶级、顶尖、尖端、顶级工艺、顶级享受、终极
- **"首/独"类**：首个、首选、独家、全网首发、全国首家、全球首发
- **权威类**：领导人推荐、机构专供、特供、国宴专用、填补国内空白、国家××机关推荐/专供、中国驰名商标、质量免检、无需国家质量检测
- **夸大类**：绝无异味、性价比之王、专车专用（无依据时）
- **绝对化**：绝对、终生、永不、绝对不起球、终生穿不坏、绝对摔不烂、100%
- **品牌类**：领袖品牌、世界领先、缔造者、至尊、巅峰
- **承诺类**：包过、保过、一本书学会、一套题学会、一次通过、一次通关；保值、升值、升值回报、立马升值、投资价值、投资回报、转手就能赚
- **迷信类**：旺夫旺子、带来好运气、增强第六感、逢凶化吉、避凶辟邪、防小人、招财、财气贵气、时来运转
- **医疗/保健**：评比、排序、指定、选用、获奖、无效退款、保险公司保险、不反复、三天即愈、根治、比手术安全、包治百病、一盒见效、彻底康复、无副作用、痊愈、立马见效、家中必备、100% 有效、零风险、无毒副作用、无依赖、安全、热销、抢购、试用、家庭必备、免费治疗、免费赠送

替代思路：用可验证的客观描述替代（材质、参数、检测报告编号、真实销量区间需有凭证）；"最受欢迎"→"很多朋友回购"；"第一品牌"→"老牌子"；"顶级工艺"→"XX 工艺（说清是什么）"。

## 9. 违规营销话术（车）

| 高危 | 处理 |
|---|---|
| 最后一单 / 最后 5 分钟（库存充足） | 删除；按真实库存说 |
| 好评返现、好评免单、全 5 星返现、好评返红包、好评才能退换、不给好评别下单、收货全额返 | 全部删除 |
| 拍了打 3 遍优先发货、call 1 加急发货、点关注送运费险/7 天无理由、扣 666 才能领福利、没关注没法买 | 删除；售后权益不与关注/评论挂钩 |
| 截屏抽奖、口头免费送（无商详页说明） | 用超级福袋/平台赠品工具，赠品写进商详页 |
| X 秒后 X 元秒杀（未按时上架/价格不符） | 按时上架，价格与宣传一致；秒杀信息写全：开始时间、商品及数量、限制条件、是否预售 |
| 宣传低价但库存为 0 / 福袋奖品与实际不符 / 宣传单量与实际不符 | 宣传与实际一致 |
